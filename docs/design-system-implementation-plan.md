# デザイントークンとCSS Modulesへの一括移行：実装計画

[改善計画](design-system-assessment.md)に従い、共通UIと両アプリを標準CSS変数・CSS Modulesへ移し、Tailwindを削除する。変更範囲が広いため、実装とレビューを13タスクに分ける。途中のタスクだけを本番へ公開せず、全タスクの完了後に一括で移行する。

この文書は実装担当者とレビュー担当者の作業用チェックリストである。チェック欄は実施結果に合わせて更新する。未完了のタスクは公開対象にしない。配置と検証用ファイルの確定先は[共通UIガイド](design-system/README.md)を参照する。

作成日：2026年10月31日。コードの確認基準：`f2632755554f5a8f640c740f00bbbfbba943fcb6`。詳細な命名・CSS規約・品質基準は改善計画を参照する。

## 進め方と依存関係

一つの統合ブランチで作業し、タスク単位でコミットとレビューを分ける。タスクの完了と本番への公開は分けて扱う。最終成果物には、旧トークン、Tailwindのクラス、旧props向けの互換処理を残さない。
